# CareerAI Platform — интеллектуальная система профориентации

Веб-платформа для профессиональной ориентации студентов и абитуриентов. Рекомендует направления подготовки бакалавриата на основе профиля навыков, интересов и результатов ЕГЭ с помощью нейросетевой модели.

## Возможности

### Публичный опросник
- **Адаптивный опрос** — вопросы ветвятся на основе предыдущих ответов
- **Этапы:** интересы → навыки → общие качества → зарплата → выбор предметов ЕГЭ → баллы ЕГЭ
- **Персонализированные рекомендации** — топ направлений с процентом совпадения и объяснением
- **Анкета вуза** — кастомные поля для сбора данных абитуриентов

### Админ-панель
- **Каталог направлений** — добавление/редактирование направлений, кодов ФГОС, описаний, ключевых навыков
- **Управление признаками** — настройки признаков профиля (оценки 1–5, зарплата, числа, текст)
- **Конструктор опросника** — вопросы с цепочками навыков и порогами ветвления
- **Анкеты вуза** — кастомные поля (текст, email, телефон, select, checkbox, date, number)
- **Медиатека** — загрузка логотипов, фонов, видео, аудио
- **Обучение модели** — запуск из админки, версии артефактов, метрики
- **Статистика и экспорт** — ответы в CSV, сессии опросов, аналитика

### ML-модель
- **Динамическая архитектура** — вход = число признаков, выход = число направлений
- **Синтетические данные** — генерация по правилам «навык → направление»
- **Версионирование** — сохранение артефактов (модель, scaler, mlb, config.json)
- **Объяснимость** — каждое направление получает объяснение соответствия

## Быстрый старт (Docker)

```bash
# 1. Копирование конфигурации
cp .env.example .env

# 2. Заполнение переменных окружения
# - POSTGRES_USER, POSTGRES_PASSWORD, POSTGRES_DB
# - SECRET_KEY (сгенерируйте надёжный)
# - DOMAIN (домен для production)

# 3. Запуск
docker compose up -d db app

# 4. Открытие в браузере
# Опросник: http://localhost:7777/
# Админ-панель: http://localhost:7777/admin (admin / admin123)
# Swagger API: http://localhost:7777/docs
```

### HTTPS (продакшен)

```bash

docker compose up -d db app nginx

# 2. Выпуск сертификата Let's Encrypt
./nginx/init-letsencrypt.sh

15 3 * * * docker compose run --rm certbot renew --webroot -w /var/www/certbot && docker compose exec nginx nginx -s reload
```

## ML-модель

### Архитектура

**Мультилейбл-нейросеть** (TensorFlow/Keras) для многоклассовой классификации с независимыми бинарными выходами:

```
Input (N признаков)
 │
 ▼
Dense(128, relu) → BatchNorm → Dropout(0.5)
 │
 ▼
Dense(64, relu) → BatchNorm → Dropout(0.5)
 │
 ▼
Dense(32, relu) → Dropout(0.3)
 │
 ▼
Dense(M, sigmoid) ← M = число направлений
```

- **Вход**: вектор из N признаков (оценки навыков 1–5, зарплата, баллы ЕГЭ, общие качества)
- **Выход**: M вероятностей (по одной на каждое направление), каждая в диапазоне 0–100%
- **Функция потерь**: `binary_crossentropy` (мультилейбл, каждое направление независимо)
- **Оптимизатор**: Adam (lr = 0.001 для обучения, 0.0001 для дообучения)
- **Метрика**: AUC (Area Under ROC Curve)
- **EarlyStopping**: patience = 10 по `val_auc`, максимум 80 эпох

### Генерация данных

Синтетическая выборка генерируется по правилам «навык → направление» и включает 10 профилей:

| Профиль | Описание | Кол-во на направление |
|---------|----------|----------------------|
| Универсальные отличники | Все навыки = 5, высокие ЕГЭ | 500 |
| Частично идеальный | 2–3 ключевых навыка = 5, остальные = 2–3.5 | 1 000 |
| Средний | Все навыки = 3–4, ЕГЭ = 60–75 (40%) | 10 000 |
| Без ЕГЭ | Навыки 2–5, все ЕГЭ = -1 | 5 000 |
| Чистый профиль | Ключевые = 5, остальные = 1 | 2 000 |
| Усиленный чистый | Ключевые = 5, профильные ЕГЭ = 80–98 | 500 |
| Мультинаправленный | 2–3 направления, чёткий контраст | 15 000 |
| Шумный | Низкий фон, случайные пики до 4.5 | 20 000 |
| Балансировка | Направление vs похожее (rival = 4.0) | 1 000 |
| Узкий профиль | 1–2 навыка направления = 5 | 1 000 |

+ профили с высоким/низким зарплатным ожиданием и смешанные мульти-профили.

### Дообучение на реальных данных

Модель можно дообучить на реальных ответах абитуриентов (`responses.csv`):

- **Режим `all`** — синтетика + реальные ответы (объединяются)
- **Режим `real_only`** — только реальные ответы
- **Fine-tuning** — старт от весов выбранной модели (lr = 0.0001)

Реальные ответы маппятся на полные названия направлений через `SHORT_NAME_MAP` (короткие кодовые названия → полные названия).

### Рекомендатель

При запросе рекомендаций:

1. Загружает артефакты последней успешной модели (`.keras`, `scaler.pkl`, `mlb.pkl`, `config.json`)
2. Масштабирует входной вектор через `StandardScaler`
3. Предсказывает вероятности через `model.predict()`
4. Сортирует направления по убыванию вероятности
5. Генерирует персонализированное объяснение на основе сильных/слабых сторон профиля

**Уровни соответствия:**

| Порог | Уровень | Вердикт |
|-------|---------|---------|
| ≥ 85% | IDEAL | Отличное соответствие |
| ≥ 70% | EXCELLENT | Хорошее соответствие |
| ≥ 55% | GOOD | Среднее соответствие |
| ≥ 40% | AVERAGE | Базовое соответствие |
| ≥ 25% | — | Начальный уровень |
| < 25% | LOW | Низкое соответствие |

### Версионирование

Каждый запуск обучения создаёт отдельную запись в `model_runs` с артефактами в `models/run_{id}/`. Рекомендатель всегда использует последнюю успешную версию, поэтому переобучение не ломает работающий сервис.

## Требования

- **Python** 3.10+
- **TensorFlow** ≥ 2.10 (для ML-модели)
- **PostgreSQL** ≥ 14 (или Docker)
- **Docker** + **Docker Compose** (опционально, для упрощённого развёртывания)
- **Nginx** (опционально, для production + HTTPS)

## Важная информация

1. **Безопасность**
 - Стартовый администратор создаётся из `INITIAL_ADMIN_USERNAME` / `INITIAL_ADMIN_PASSWORD` — **обязательно смените пароль после первого входа**
 - В продакшене задайте надёжный `SECRET_KEY`, включите `COOKIE_SECURE=true` и используйте HTTPS через nginx
 - Rate limiting на вход: 10 попыток в минуту

2. **Данные**
 - Синтетические данные обучения — заготовка правил «навык → направление»
 - Для качества нужна валидация на реальных анкетах и дообучение на собранных ответах
 - Все ответы сохраняются в БД для аналитики и дообучения

3. **Масштабирование**
 - Приложение stateless, можно запускать несколько воркеров uvicorn
 - PostgreSQL поддерживает репликацию для чтения
 - Nginx поддерживает upstream-группы для балансировки
