Разработана адаптивная multilabel-нейросеть для рекомендации направлений подготовки абитуриентам на основе их профиля навыков, интересов и результатов ЕГЭ. Проблема субъективности традиционной профориентации решается через модель с динамической архитектурой: размер входа и выхода адаптируется под текущий каталог признаков и направлений без переделки структуры. Синтетическая обучающая выборка генерируется по правилам «навык → направление» с учётом 10 профилей абитуриентов (универсальные отличники, частичные профили, шумные данные, балансировка схожих направлений и др.), что обеспечивает покрытие реального распределения кандидатов. Модель дообучается на реальных ответах абитуриентов из базы данных вуза, что позволяет системе непрерывно улучшать точность рекомендаций по мере накопления данных. Реализован рекомендатель на основе нейросетевой мультилейбл-классификации, формирующий топ-N направлений с процентом совпадения и персонализированным объяснением на основе сильных и слабых сторон профиля. Проведён эксперимент с метриками качества: top-1/top-3/top-5 accuracy, Macro-F1, Macro-AUC по каждому направлению. Практическая значимость — автоматизация и персонализация профориентации с объяснимыми рекомендациями, масштабируемость на любой каталог направлений и непрерывное улучшение модели на реальных данных.
