**Название:** Разработка адаптивной модели оценки способностей и предрасположенностей абитуриента для рекомендации выбора специальности с применением методов машинного обучения

## 1. Постановка проблемы

Традиционные методы профориентации в вузах опираются на анкетирование ручной работы, экспертную оценку и статические рекомендации, не учитывающие индивидуальное сочетание навыков, интересов и результатов ЕГЭ конкретного абитуриента. Существующие онлайн-тесты дают общий результат без персонализированного обоснования и не адаптируются к каталогу направлений конкретного вуза. Возникает потребность в автоматизированной системе, которая способна на основе многомерного профиля абитуриента формировать ранжированный список подходящих направлений с количественной оценкой соответствия и объяснимой аргументацией. Применение методов машинного обучения, в частности нейросетевой классификации с множественными метками, представляет научный интерес, поскольку структура задачи (мультилейбл, динамическое число классов, необходимость объяснимости) требует нестандартного подхода к архитектуре модели и генерации обучающих данных.

## 2. Цель работы

Разработка адаптивной multilabel-модели на основе нейронной сети для рекомендации направлений подготовки бакалавриата на основе профиля навыков, интересов и результатов ЕГЭ абитуриента с персонализированным объяснением соответствия.

## 3. Объект и материал исследования

**Объект исследования** — процесс профессиональной ориентации абитуриентов при выборе направления подготовки.

**Материал исследования:**

- Каталог направлений подготовки Университета «Дубна» с кодами ФГОС, описаниями и ключевыми навыками.
- Система признаков профиля абитуриента: оценки навыков и качеств (1–5), баллы ЕГЭ по 11 предметам, желаемый уровень заработной платы.
- Реальные ответы абитуриентов, собранные через публичный опросник и сохранённые в базе данных PostgreSQL в формате CSV.
- Синтетическая обучающая выборка, генерируемая по правилам «навык → направление» с учётом структуры каталога.

## 4. Предлагаемое решение

Разработана веб-платформа CareerAI, включающая публичный опросник, админ-панель и ML-компонент.

**Архитектура модели.** Мультилейбл-нейросеть (TensorFlow/Keras) с динамической архитектурой: входной слой имеет размерность N (число признаков), выходной — M (число направлений). Скрытые слои: Dense(128, ReLU) → BatchNorm → Dropout(0.5) → Dense(64, ReLU) → BatchNorm → Dropout(0.5) → Dense(32, ReLU) → Dropout(0.3) → Dense(M, sigmoid). Функция потерь — binary_crossentropy (каждое направление предсказывается независимо). Оптимизатор — Adam (lr = 0.001 при обучении с нуля, lr = 0.0001 при дообучении). Метрика качества — AUC-ROC, EarlyStopping по val_auc (patience = 10, максимум 80 эпох).

**Генерация синтетических данных.** Обучающая выборка формируется по 10 профилям абитуриентов: универсальные отличники (все навыки = 5, 500 образцов на направление); частично идеальный профиль (2–3 ключевых навыка = 5, остальные = 2–3.5, 1000 образцов); средний профиль (все навыки = 3–4, 10 000 образцов); без ЕГЭ (все ЕГЭ = −1, 5000 образцов); чистый профиль (ключевые = 5, остальные = 1, 2000 образцов); усиленный чистый (высокие ЕГЭ по профильным предметам, 500 образцов); мультинаправленный (2–3 направления с контрастом, 15 000 образцов); шумный (низкий фон, случайные пики, 20 000 образцов); балансировка (направление vs похожий соперник с навыком = 4.0, 1000 образцов); узкий профиль (1–2 навыка = 5, 1000 образцов). Дополнительно генерируются профили с высоким и низким зарплатным ожиданием и смешанные мульти-профили.

**Дообучение на реальных данных.** Модель дообучается на ответах абитуриентов из CSV. Реализован маппинг коротких названий направлений (введённых абитуриентами) на полные официальные наименования через словарь SHORT_NAME_MAP и частичное посимвольное сопоставление. Два режима обучения: объединение синтетики с реальными данными и обучение только на реальных ответах. Fine-tuning стартует от весов предыдущей модели.

**Рекомендатель.** Загружает артефакты последней обученной модели, масштабирует входной вектор через StandardScaler, формирует предсказания и ранжирует направления. Каждый результат сопровождается уровнем соответствия (IDEAL ≥ 85 %, EXCELLENT ≥ 70 %, GOOD ≥ 55 %, AVERAGE ≥ 40 %) и текстовым объяснением, указывающим сильные стороны профиля и, при низком совпадении, навыки, требующие развития.

**Версионирование.** Каждый запуск обучения сохраняет отдельную версию модели (.keras), скалер, бинарайзер и конфигурацию в именованной директории. Рекомендатель всегда использует последнюю успешную версию, что исключает поломку работающего сервиса при переобучении.

## 5. Результаты

1. **Разработана и реализована multilabel-модель** с динамической архитектурой, адаптирующейся к числу признаков и направлений без изменения структуры сети.

2. **Создан метод генерации синтетических обучающих данных** на основе правил «навык → направление» с 10 профилями абитуриентов, обеспечивающий покрытие широкого спектра реальных комбинаций навыков и интересов.

3. **Реализован механизм дообучения модели на реальных данных** с маппингом неформатированных названий направлений и весовым усилением реальных примеров.

4. **Разработан рекомендатель с объяснимостью**, формирующий персонализированный топ направлений с количественной оценкой вероятности соответствия и текстовым обоснованием на основе сильных и слабых сторон профиля абитуриента.

5. **Проведён эксперимент с метриками качества**: top-1/top-3/top-5 accuracy, Macro-Precision, Macro-Recall, Macro-F1, Macro-AUC, а также F1 по каждому направлению отдельно.

6. **Спроектирована архитектура системы версионирования моделей**, позволяющая хранить несколько версий, отслеживать метрики каждого запуска и откатываться к предыдущей стабильной версии.

## 6. Практическое значение и ограничения

**Область применения:** системы профориентации вузов, онлайн-сервисы выбора образовательных программ, адаптивные рекомендательные системы в образовании. Модель может быть интегрирована в веб-сайт вуза или мобильное приложение, а также использована как самостоятельный сервис по API.

**Границы применимости:**
- Модель обучается на синтетических данных, поэтому её точность зависит от качества и полноты каталога направлений и навыков конкретного вуза.
- Для достижения высокой точности требуется накопление реальных данных об ответах абитуриентов.
- Модель не учитывает внешние факторы: стоимость обучения, географию, конкурсный отбор, стипендии.
- Рекомендации носят информационный характер; окончательное решение остаётся за абитуриентом и консультантом вуза.

## 7. Вывод

Разработана адаптивная multilabel-нейросеть для профориентации абитуриентов, объединяющая генерацию синтетических данных по правилам «навык → направление», дообучение на реальных ответах и объяснимый рекомендатель с персонализированными уровнями соответствия. Система обеспечивает автоматизацию, масштабируемость на любой каталог направлений и непрерывное улучшение качества на основе поступающих данных.
